# SoundIris

SoundIris employs concurrent processing, leveraging multi-threaded architecture to optimize polyphonic-synthesis and machine-learning-integration capabilities on a dedicated audio processor.

SoundIris is built to be simple and practical, focusing on doing one thing well.

2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
